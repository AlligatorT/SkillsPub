## 0.1.0 (2026-09-16)

Initial public release: skill × target switch matrix, on/off management with parking, Shared Agent Skills (`~/.agents/skills`) lifecycle via the `skills` CLI, managed Harness adapters for Pi and Grok Build, discoverable adapters for Claude Code, drift/reconcile flows, and the interactive TUI.
